# Portfolio: In Silico Forensic Biology & Molecular Tracking

This repository serves as a professional portfolio containing verified case files and computational laboratory simulations mapping trace biological evidence.

## Completed Case Files

### Case 01: Wildlife Forensic Taxonomic Classification
* **Objective:** Genetic alignment and molecular classification of an unlabelled biological matrix seized during a mock anti-poaching sweep.
* **Methodology:** Fast Minimum Evolution tree construction via pairwise alignment utilizing the **NCBI BLAST** framework.
* **Finding:** Definitive taxonomic clustering confirming target origin as *Bison bonasus* (European Bison).

###  Case 02: Human DNA Target Selection & PCR Primer Design
* **Objective:** Constructing custom molecular target hooks to amplify highly variable human STR regions for identification profiles.
* **Methodology:** Computational thermodynamic balancing (Tm/GC-ratio tracking) of the `HUMTH01` locus utilizing **Benchling**.
